# Vectors

`lomboksecurity-vectors-v1.json` is the cross-language test contract for LombokSecurity.

- SHA-256: `bc39de3f3d6de49dc8e90d0bde1ff0ff571d2160477a58b4f83720f31ff9693f` (must equal the hash in `docs/SPEC_LombokSecurity_v0.1.0.md`).
- Generated by `scripts/gen-vectors.mjs`. Group `golden`: expectations are written by hand or copied from FIPS 180-4 and RFC 4231, then matched against the TypeScript port during generation; hash and HMAC expectations are also recomputed with `node:crypto`. Group `generated-regression`: seeded random inputs, with expectations from the TypeScript port (hashes checked with `node:crypto`) confirmed by the Rust port.
- Every case calls the function `fn` with `args`; `expect` has the form `{ "result": ... }` or `{ "error": code }`.
- Every claimed port MUST run every case.
- Count: 341 cases (181 golden cases with hand-written or standard expectations, 160 generated regression cases).
